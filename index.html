„Prüfen“ = Touren, die nicht in der Firma begonnen haben und weit weg gingen – oft Urlaub. Privat → „war frei“, sonst „war Arbeit“.

„In Maps öffnen“ zeigt die genaue Unterkunft mit Namen. Trag dir Name, Sterne und eine Notiz ein – das bleibt gespeichert und taucht nächstes Jahr beim gleichen Hotel wieder auf.

So wird Arbeit gezählt
  • Eine Arbeitstour beginnt, wenn du an einem Arbeitstag von der Firma wegfährst – oder morgens direkt von daheim zur Baustelle.
  • Sie endet, sobald du wieder in der Firma oder daheim bist. Fahrten danach (abends, privat) zählen nicht.
  • Der Weg daheim ↔ Firma zählt nie. Mehrtägige Touren mit Hotel laufen durch bis zur Rückkehr.
  • Nur Arbeitstage zählen – Feiertage und eingetragene freie Tage nicht.
So bekommst du einen Schlüssel
  1. console.cloud.google.com öffnen, Projekt anlegen, Abrechnungskonto verbinden (für ein paar Dutzend Abfragen im Monat fallen keine Kosten an).
  2. Unter „APIs & Dienste → Bibliothek“ Maps JavaScript API und Places API (New) aktivieren.
  3. „Anmeldedaten → Anmeldedaten erstellen → API-Schlüssel“.
  4. Schlüssel einschränken: Websites → https://fubee00.github.io/* (bzw. eure Adresse), APIs → nur die zwei oben.
Der Schlüssel bleibt nur in diesem Browser gespeichert. Funktioniert auf GitHub Pages, nicht in der Claude-Vorschau.
